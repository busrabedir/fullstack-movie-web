## 🎬 Filmania

Filmania is a full-stack movie management application where users can explore movies, search for their favourite films and view detailed movie information. Users can also add new movies and delete existing ones through a simple and modern interface. The project features a responsive design and provides seamless data management through a custom REST API.

## ✨ Features
- Browse all movies on the homepage.
- Search movies by title, director, cast or genre.
- View detailed information about each movie.
- Add new movies with a custom form.
- Responsive and modern UI

## 🛠️ Technologies
## Frontend :

- React
- Tailwind CSS
- React Router DOM
- TanStack React Query
- Axios
- React Toastify
- Lucide React & React Icons

## Backend :

- Node.js
- REST API
- CORS
- Crypto (UUID generation)

## 💻 Installation & Setup
1. Clone the repository
2. Install backend dependencies and start the server
```
cd backend
npm install
npm start
```
4. Install frontend dependencies and start the development server
Open a new terminal:
```
cd frontend
npm install
npm run dev
```
